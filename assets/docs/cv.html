Proyectos destacados

Gestor de Citas Médicas

Java · JavaFX · PostgreSQL · JDBC

Sistema de escritorio para administrar pacientes, médicos y agenda de citas. Arquitectura MVC en capas (vista FXML, controlador, servicio y DAO), esquema relacional normalizado (3FN), validación de horarios y especificación de requisitos funcionales y no funcionales.

Catálogo de Productos

Java · Swing

Aplicación con arquitectura en capas y POO que gestiona niveles de acceso para administrador y usuario. Incluye inicio de sesión por roles, altas, bajas y cambios de productos y categorías, búsqueda y filtrado, aplicando encapsulamiento, herencia y polimorfismo.

Cerberus IDE

Java · JavaFX · Maven

Lenguaje de programación educativo en español diseñado para facilitar el aprendizaje de la programación y la POO. Incluye editor con análisis léxico y sintáctico, palabras reservadas en español (si/entonces, mientras/hacer) y soporte de clases y métodos con sintaxis adaptada.

Control Embebido con PIC18F4550

C · XC8 · MPLAB X · Proteus

Firmware en C para el microcontrolador PIC18F4550 orientado al manejo de puertos de entrada/salida, temporizadores e interrupciones. Configuración de E/S, lectura de entradas digitales, control de salidas y validación en simulación antes del montaje físico.

Diseño de Bases de Datos Relacionales

PostgreSQL · MariaDB · SQL

Modelado entidad-relación, normalización hasta tercera forma normal e implementación física de esquemas en PostgreSQL y MariaDB, con restricciones de integridad, llaves foráneas, vistas y consultas complejas con JOIN y subconsultas.

Portafolio Web Profesional

HTML5 · CSS3 · JavaScript · PHP

SPA estática sin dependencias externas con navegación por historial, carrusel accesible, modales, filtrado dinámico, formulario de contacto con validación en cliente y arquitectura i18n ES/EN. Diseño Mobile-First, transiciones ágiles y contraste conforme a WCAG 2.1 AA.
